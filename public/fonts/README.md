# Bundled PDF fonts

KnowBoth embeds **Nanum Gothic Regular** and **Nanum Gothic Bold** in downloaded
PDF reports so Korean text remains searchable and renders consistently.

- Source: [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/nanumgothic)
- Copyright: NAVER Corporation
- License: SIL Open Font License 1.1
- License text: [`OFL.txt`](./OFL.txt)

The font files are redistributed without modification under the OFL. They are
loaded only when a user asks to create a PDF.
